Goal: develop a cute fighting game for myself and my friends to play.

Key features:
- simple blocky pixel graphics [inspo](https://x.com/sammycore333/status/2107231393889812544?s=20)
- hold back to block
- lots of command normals
- motion specials
- 1v1
- "arial footsies"
- two jumps, two air dashes, every character
- extra jump and dash on special hit
- buffer dash
